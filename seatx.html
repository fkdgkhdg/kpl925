次日 = 上榜日的下一个交易日收盘对比上榜日收盘；涨停=次日涨幅≥9.7% 且收盘=当日最高；大面=次日收盘≤-5%；跌停=≤-9.5%；天地板=次日最高≥9.7% 且最低≤-9.5%。

F. 龙虎榜板块活跃（题材口径＝同花顺涨停原因）

把每个交易日上龙虎榜的主板股，按同花顺涨停原因归类 —— 就是上面 A/D 表里那些绿色题材 chip 的名字。看哪个板块在扎堆上榜 / 净买最多。
同一只票有多个原因会计入多个题材（如「机器人轴承 + 汽车轴承」），所以各题材只数相加大于上榜股数。点题材名 → 展开该题材当天的上榜个股。
读法：上榜只数多 + 净买为正 = 板块里资金在抢（接力题材）；只数多但净卖 = 板块高位出货（分歧/退潮）。净买＝当日龙虎榜买五合计−卖五合计，只算主板非 ST。窗口 >1 日时同一只票多次上榜会重复计入，看的是「上榜频次」；末列个股按净买绝对值取前 3。

D. 最新一档龙虎榜（-，收盘后已出 · 已并入 A）

A 节那张表是「当个交易日的 9:25 名单」，席位取自名单里股票的涨停日，所以永远是前一日的榜。
这一节直接取最近一档已出的龙虎榜（含当日涨停股），也就是明早 9:25 名单会用到的席位结构 —— 收盘后当晚就能看。
读法：买一占比是放大器，不是方向。小盘缩量时它=筹码锁死（利好）；高位 + 大成交时它=一票兑现就崩（警报）。龙渊阁说的「超两成放弃」，前提正是高位连板 + 区间成交大。样本 n<100 的档位只作参考。

E. 最近高连板股活跃席位（-）

取最近 N 个交易日里「当日涨停且 ≥3 板」的主板股，汇总其上榜席位。点任意席位行 → 展开它参与过哪些票。
板数 = 当日往前连续涨停数；性质（配色同主页面）：散户通道（拉萨天团 + 国信浙江互联网）/ 游资·营业部 / 机构专用 / 北向（沪深股通）。历史大面率 = 该席位历史净卖出后次日收盘 ≤-5% 的占比（红 ≥45%、橙 33~44%）；「净卖后次日均」= 同样口径的平均次日涨跌幅，n 为样本数。
